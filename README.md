# SkillBridge

SkillBridge is an AI-powered, gamified career-readiness platform for Indonesian vocational high-school students (SMK). It helps students understand the expectations of entry-level work, practise realistic workplace situations, and build evidence of their skills through structured feedback.

> **Learn by doing. Show what you can do.**

## Why SkillBridge?

Students often need more than course completion or a certificate to prepare for work. They need opportunities to practise communication, problem solving, teamwork, professional conduct, and role-specific tasks—and to understand how their performance can improve.

SkillBridge connects those needs in one learning loop:

1. **Discover** — choose a career goal and explore relevant workplace situations.
2. **Practise** — complete short, scenario-based career missions.
3. **Assess** — receive rubric-based feedback on the skills demonstrated.
4. **Improve** — address skill gaps and take the next mission.

Gamification encourages consistent practice, while rubrics and submitted work provide the meaningful evidence of competence.

## Who it serves

- **Students in grades XI–XII** preparing for work after graduation
- **Recent graduates** improving their applications and workplace skills
- **Teachers and BKK teams** supporting career readiness and tracking progress
- **Schools and decision-makers** evaluating structured readiness programs
- **Industry practitioners** helping define credible entry-level standards

The foundation is designed for students across study programs—not only technology. Career missions can support administration and finance, hospitality and service, logistics and operations, digital technology, and other vocational pathways.

## Core experience

### Universal readiness

Students build transferable skills that matter across roles:

- Professional communication
- Workplace ethics and reliability
- Problem solving and decision making
- Teamwork and collaboration
- Recruitment literacy, including CV and portfolio preparation
- Career exploration and goal setting

### Career missions

Short simulations turn workplace expectations into practical tasks. Examples include:

| Pathway | Example mission | Evidence produced |
| --- | --- | --- |
| Administration / finance | Find discrepancies between an invoice and a purchase order | Corrected document and findings report |
| Hospitality / service | Respond to a customer complaint within SOP limits | Written response and escalation note |
| Logistics / operations | Prioritise orders when stock is limited | Prioritisation decision and rationale |
| Digital technology | Fix a small bug from a user brief | Updated output and technical documentation |

Each mission is assessed against a clear rubric. Automated assistance can provide immediate guidance, while important scores remain reviewable by a teacher or qualified practitioner.

## Designed for responsible use

SkillBridge supports learning and assessment; it does not promise employment or predict whether a student will be hired by a particular company.

- AI feedback is an assistant, not the sole decision-maker for high-impact outcomes.
- Rubrics should be reviewed and calibrated with educators and industry practitioners.
- Student data, assessment results, CVs, and portfolios require appropriate consent—especially for users under 18.
- Research and reporting should protect participant identity and avoid collecting sensitive information without a clear need.

## For schools and industry

SkillBridge is designed to connect three groups:

- Students receive guided practice, actionable feedback, and a portfolio of work.
- Schools and BKK teams gain a clearer view of progress and competency gaps.
- Industry partners help shape realistic challenges and credible assessment standards.

The platform can support school-based programs, classroom enrichment, career guidance, and industry-informed assessment.

## Getting started

### Prerequisites

- Node.js (LTS recommended)
- npm
- Expo CLI tooling
- An Android emulator, iOS simulator, or physical device with Expo Go

### Install and run

```bash
npm install
npm start
```

Then choose a target from the Expo developer menu, or use one of the platform scripts:

```bash
npm run android
npm run ios
npm run web
```

Run the project checks with:

```bash
npm run lint
```

## Product principles

1. **Evidence over assumptions** — measure demonstrated skills, not just activity or XP.
2. **Practice before prediction** — help students improve before making decisions about fit.
3. **Universal foundation, relevant pathways** — start with transferable skills and add role-specific missions.
4. **Human-guided assessment** — use AI to assist educators and reviewers, not replace their judgement.
5. **Inclusive by design** — account for differences in study program, location, experience, and post-graduation goals.
